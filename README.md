# Word Factory

Free spelling, word-parts and word-meaning practice for grades 1 to 5, built on
Florida's B.E.S.T. Standards for English Language Arts. Part of the learning
games at [mehdee.com/games](https://mehdee.com/games/).

## What it covers

All **30** B.E.S.T. ELA benchmarks for grades 1 to 5 that concern words and
spelling, six per grade:

| Strand | Benchmark | What it is |
|---|---|---|
| Foundations | `F.1.3` | Phonics and word analysis: digraphs and blends, r-controlled vowels, vowel teams and diphthongs, syllable types, Greek and Latin roots, multisyllabic words |
| Foundations | `F.1.4` | Fluency: sight words and the spellings that come up most often |
| Vocabulary | `V.1.1` | Academic vocabulary |
| Vocabulary | `V.1.2` | Morphology: base words, inflections, affixes, roots, and by grade 5 the link between affixes and parts of speech |
| Vocabulary | `V.1.3` | Context clues, multiple-meaning words, figurative language, shades of meaning |
| Communication | `C.3.1` | The conventions benchmark, which carries each grade's spelling and grammar skills |

Florida assesses this material through **FAST ELA Reading**, grades 3 and up.

Not affiliated with or endorsed by the Florida Department of Education.

## Why the misspellings are precomputed

A spelling question is only fair if none of the wrong options is itself a real
word. Generating misspellings at runtime produced `been` against `bean` and
`come` against `came`, which gives a child two defensible answers.

Every distractor in `MISSPELL` is generated by swapping spelling patterns,
doubling, dropping and transposing letters, then **rejected if it appears in the
system dictionary**. Regenerate with:

```
node tools/gen-misspellings.js
```

## Privacy

No accounts, no ads, no cookies, no advertising or profiling scripts. The child's
name and progress live in `localStorage` on that device only and are never
transmitted. The one server request is an anonymous page-view count through
Cloudflare Web Analytics: cookieless, no fingerprinting, no cross-site tracking,
and it identifies nobody. The game still works offline after the first load; the
beacon simply fails silently.
A parent reset on the start screen erases all saved progress.
